A one-line excuse from a robot vacuum for missing a spot — written by a small
machine keeping a straight face. The program writes the line to
`/output/entry.txt` (1–140 characters, UTF-8).

## The excuse

> "My cliff sensors flagged that crumb as a cliff. I'm not risking my life for one crumb."

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```

Node 22+, standard library only, deterministic: the same line every run.
